# Phase 0 UI audit

Scope: changed recovery, raw export, replacement, and cloud deletion controls. Existing TAPE colors, type, and dialog components supply the design direction. Design read: trading terminal for players recovering progress, using the established compact terminal language, ENERGY 1 / RHYTHM 1 / MOTION 1. No visual assets were created.

The R-numbers refer to the external `antislop` agent skill used for this audit. They are audit references, not repository requirements. The behavior claims below refer only to the controls reviewed at the time; cloud deletion now also shows a disabled, labeled busy state while each row is checked.

Rule key: R-02 copywriting; R-03 mobile layout; R-17 real numbers; R-18 real testimonials; R-23 asset clarification; R-24 working navigation; R-26 working controls; R-27 empty/loading/error states; R-31 purposeful decisions; R-32 keyboard access; R-33 direct source edits; R-35 interactive verification; R-36 truthful claims; R-37 design direction; R-38 real content or labeled placeholders.

## Findings addressed

1. HIGH, R-26/R-27: Raw export initially lacked feedback when IndexedDB rejected the read. The action now reports a per-slot error and offers a retry.
2. HIGH, R-03/R-32: The new raw export control initially had a small touch target and no explicit keyboard focus treatment. It now has a 44px minimum height and visible focus outline.
